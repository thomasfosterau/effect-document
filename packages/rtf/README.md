# @thomasfosterau/effect-rtf

Rich Text Format reader and writer for [effect-document](https://github.com/thomasfosterau/effect-document): paragraphs and headings with bold, italic, underline and strikeout runs.

```ts
import * as Rtf from "@thomasfosterau/effect-rtf";
```

See the [repository README](https://github.com/thomasfosterau/effect-document#readme) for the schema, profiles and conversion model.
