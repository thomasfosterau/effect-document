- [#265](https://github.com/thomasfosterau/effect-document/pull/265) [`6fbeb70`](https://github.com/thomasfosterau/effect-document/commit/6fbeb706af96264fdefa03357f868314959cb5f1) Thanks [@thomasfosterau](https://github.com/thomasfosterau)! - Loss reports say where and how badly ([#112](https://github.com/thomasfosterau/effect-document/issues/112)). - [#268](https://github.com/thomasfosterau/effect-document/pull/268) [`2a64ad5`](https://github.com/thomasfosterau/effect-document/commit/2a64ad514b743f9fe97aff7bfbb6e312ff8b82d6) Thanks [@thomasfosterau](https://github.com/thomasfosterau)! - Preview reads ([#188](https://github.com/thomasfosterau/effect-document/issues/188)). - [#265](https://github.com/thomasfosterau/effect-document/pull/265) [`cfc1380`](https://github.com/thomasfosterau/effect-document/commit/cfc13808b33e248adb0f140999ab44942716fac4) Thanks [@thomasfosterau](https://github.com/thomasfosterau)! - Profiles take two more kinds of structural rule ([#126](https://github.com/thomasfosterau/effect-document/issues/126)). `onlyWithin` allows a feature only inside a given node, optionally one whose field holds one of a set of values. `fieldValues` restricts the values a node's own field may hold. `is` / `validate` reject a document that breaks one, and `narrow` converts the node as if the profile lacked the feature there, with the rule's reason in the loss entry. `Profile` gains `onlyWithin` and `fieldValues` (both empty unless given).
