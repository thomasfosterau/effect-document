# AGENTS.md: packages/core

The published package. The core is the schema (`src/schema`), profiles (`src/profile`) and the I/O pipeline (`src/io`), on the root entry and `./schema`, `./profile`, `./profiles`, `./io`. Each format family is a nested subpath in its own directory (`src/csv`, `src/rtf`, `src/ooxml`, `src/pdf`, `src/iwork`, plus `src/encoding`), tested under `test/<format>/`. No format is on the root barrel.

## Boundary

A consumer who uses no format installs no effect-parse and bundles no fflate, so reach is load-bearing:

- **The core** imports no format and none of the dependencies. Format-specific rules live in the format's directory, behind its profile.
- **Each format** imports the core by relative path (never the package's own name, which resolves to `dist/`) and never another format.
- `@thomasfosterau/effect-parse` (optional peer) is reached only from `./csv`, `./rtf`, `./ooxml*`, `./iwork*`; `fflate` only from `./ooxml*`, `./pdf*`, `./iwork*`; `@thomasfosterau/effect-ext` only from `./encoding`. `test/module-graph.test.ts`, `vp run check:dist` and the `.fallowrc.json` zones all pin this; a new dependency changes all three.
- A new entry is added to `entries` in `vite.config.ts`, `exports` in `package.json`, `paths` in `tsconfig.base.json` and `entry` in `.fallowrc.json`.

## Invariants

- **The profile is the contract.** A reader returns `Doc<F>` for its format's profile and a writer accepts only that; a feature a writer can't encode is excluded from the profile, never dropped at write time. `test/integration/type-level.types.ts` pins the compile-time guarantees.
- **`Doc<F>` is a phantom brand**, produced only by a profile's `validate` / `schema`, `narrow` and `trustAs`. Readers use `trustAs` for their own output only.
- **Nothing is lost silently.** `narrow` records every drop or down-conversion as a `LossEntry`, in document order, degrading content to a readable form before dropping it. Non-fatal reader / writer issues are `Diagnostic`s logged through `logDiagnostic` (in a per-value loop, gather and log once); a diagnostic's `code` (`<format>.<issue>`) is API.
- **The schema is the wire format.** Every node round-trips through `Schema.encode` / `decode`, and the stack-safe codec (`schema/codec.ts`) must agree: a new node needs its `*Encoded` interface, its place in the node unions, a `TAG_FEATURE` entry, `narrow` and `collectFeatures` handling, and an entry in the codec's kind tables naming its recursive fields.
- **Rows and cells are positional and may be plain.** A row's cell at position `n` is column `n` (a node, or a bare number / string / boolean; `undefined` is a gap, never an array hole); a worksheet row is a `SheetRow` or a plain array implying the next index. Read them through `rowsOf`, `rowEntries`, `cellOf`, `cellAt`.
- **Trusted constructors** (`schema/trusted.ts`: `cell.*`, `str`, `sheetRow*`, `sparseRow`, `worksheet*`) skip the schema pass only for input their guards accept; the result must be `instanceof`, `Equal.equals` to and key-ordered like the `new` one. `worksheetOfTrustedRows` is the one unchecked constructor, for a reader's own typed rows.
- **Fast paths agree with the general path.** The CSV scanner and one-pass reader (`csv/fast.ts`, `csv/fused.ts`), the XLSX `sheetData` scanner and the OOXML content scanner hand anything they don't recognise to the general path, so results and errors are identical; differential tests compare them, and grow with the fast path.
- **Errors are tagged** (`ParseError` with a shared `ParseErrorCode`, `WriteError`, `ProfileViolation`, `ConversionError`); their tags and fields are API. Inner layers (PDF objects, the iWork codec) throw their own tagged errors; readers convert them.
- **Detection looks at content, never names, and never fails**: a format's `sniff` answers only for content its reader would take; extensions and MIME types only break ties.
- **Writers are byte-reproducible**: fixed ZIP mtimes, derived (not random) ids, no current dates.

## Formats

- **CSV**: one `Worksheet` of plain rows; type inference is per column by default and lossless to turn off; numbers are kept only when the double holds the written digits. The whole-text and streaming scanners must agree across chunk boundaries. Synthesis is reproducible per seed.
- **OOXML**: each of XLSX, DOCX, PPTX imports only `ooxml/shared`, never another. Parts are found through relationships. PPTX text inherits list styles through placeholder, layout and master; a missing layout or master is a diagnostic, not a failure.
- **RTF**: the lexer is total; unmodelled destinations are skipped via `DESTINATIONS`.
- **PDF**: `src/pdf/cos` imports nothing from `src/pdf/text` or the reader / writer. Malformed input is repaired, recursion is bounded, encrypted files are refused. The reader prefers the structure tree and otherwise infers structure from layout; OCR is injected, never bundled. The writer tags its output and embeds no fonts. `src/pdf/text/data.ts` is generated by `scripts/generate-pdf-data.py`.
- **iWork**: read-only. Type ids and field numbers come from `src/iwork/schema.generated.ts`, generated by `scripts/generate-iwork-schema.ts` from `vendor/iwork-protos/`; never type a number in. Cross-component lookups go through the lazy resolver. Fixtures keep their attribution (`test/iwork/fixtures/ATTRIBUTION.md`).
