# Test fixtures

Real-world PDFs from other producers, so the reader is exercised on files it didn't write itself.

- `libreoffice.pdf` - `libreoffice.html` converted by LibreOffice 24.2 (`soffice --headless --convert-to pdf:writer_pdf_Export libreoffice.html`). Subset-embedded TrueType fonts (Inter, Liberation Serif, WenQuanYi Zen Hei, OpenSymbol) with `/ToUnicode` CMaps, Type 0 fonts, link annotations, Greek/Cyrillic/CJK text.
- `reportlab.pdf` - generated by `reportlab.py` with ReportLab 4. Standard 14 fonts, a title, headings, a bulleted list, a link and a code block.

The font subsets embedded in `libreoffice.pdf` are under licences that permit embedding and redistribution: SIL Open Font License (Inter, Liberation), GPL with the font embedding exception (WenQuanYi Zen Hei) and MPL 2.0 (OpenSymbol).
