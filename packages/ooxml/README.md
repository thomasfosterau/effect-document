# @thomasfosterau/effect-document-ooxml

Office Open XML readers and writers for [effect-document](https://github.com/thomasfosterau/effect-document): Excel (`Xlsx`), Word (`Docx`) and PowerPoint (`Pptx`).

```ts
import { Docx, Pptx, Xlsx } from "@thomasfosterau/effect-document-ooxml";
// or one format at a time
import * as Xlsx from "@thomasfosterau/effect-document-ooxml/xlsx";
```

See the [repository README](https://github.com/thomasfosterau/effect-document#readme) for the schema, profiles and conversion model.
